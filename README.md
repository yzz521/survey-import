# 问卷批量导入工具

把 Excel 问卷批量写入外链问卷系统（草稿），可带上门头照和定位。给执行同事用：双击启动，浏览器里勾选门店再导入。

## 同事怎么用（推荐）

**Mac：** 双击 `启动工具.command`  
第一次 macOS 可能提示「无法打开」，请右键 → 打开。随后会自动装依赖并打开浏览器。

**Windows：** 双击 `start.bat`  
需已安装 [Python 3](https://www.python.org/downloads/)，安装时勾选 *Add python.exe to PATH*。

浏览器打开后：

1. 填三个路径（或点「选文件 / 选目录」）  
   - **清单**：门店外链清单（xlsx / xls / csv）  
   - **问卷**：各店问卷所在文件夹  
   - **照片**：可选。`门店编号-店名/门头照.jpg`
2. 点 **应用并重载**
3. 先点一家店的 **预览** 看是否对得上
4. 勾选门店 → **导入草稿**（只写草稿，不提交）

关掉启动时弹出的那个黑色/白色终端窗口，工具就会停。

## 问卷和照片怎么命名

```
Excel问卷/
  Y10018017-暴龙专卖成都春熙路店.xlsx
照片/
  Y10018017-暴龙专卖成都春熙路店/
    门头照.jpg                 ← 自动上传到「门头及店铺外观照片」
    店铺形象负面照片.jpg       ← 有违规才放，会传到「扣分证据」
```

门头照若带 GPS（手机拍照一般有），会自动写入「到店定位」。没有 GPS 的店，定位仍要进系统手补。

## 注意

- **默认只写草稿。**「导入并提交」会进审核，审核打回前不能改，要点两次确认。
- 已提交的报告默认跳过。确需覆盖再勾「强制覆盖已提交」。
- 路径和导入记录存在本机 `data/imports.db`，不会上传到 GitHub。

## 开发者手动启动

```bash
cd survey-import
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

然后打开 http://127.0.0.1:8765

## 换月复用

换新的门店清单、问卷目录、照片目录，页面上改路径点「应用并重载」即可。问卷题目文本变了也没关系，按文本重新匹配，预览里可以抽查匹配率。
